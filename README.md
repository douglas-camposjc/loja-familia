# Loja da Família

Prateleira dos apps da família do Douglas: aqui ficam **só os APKs** (nas *Releases*) e o **catálogo** (`catalogo.json`) que o app **Loja da Família** lê para mostrar o que dá para instalar e atualizar.

O código dos apps fica em outro repositório, privado.

- `catalogo.json`: a lista de apps, cada um com a versão mais nova e o link do APK.
- *Releases*: um lançamento por versão de cada app (ex.: `controle_tv-0.3.0`).

Os APKs são assinados com a chave da família. Não instale APK com o mesmo nome vindo de outro lugar.
